# Admin Dashboard
https://pranaybhardwaj29.github.io/admin-dashboard/

- A simple admin dashboard built with HTML and CSS. The page includes a sidebar, top navigation, project cards, announcements, and trending sections.

## Features
- Responsive dashboard layout
- Sidebar navigation
- Search and user profile area
- Project overview cards
- Announcements and trending panels
- Clean, modern styling

## Tech Stack
- HTML
- CSS

## Project Structure
- `index.html` — main dashboard layout
- `style.css` — dashboard styling
- `svg/` — icons and assets

## Run locally
1. Clone the repository
2. Open `index.html` in your browser

## Preview
You can view the dashboard directly by opening the HTML file in a browser.
